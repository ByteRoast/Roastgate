# GeoIP test fixtures

`GeoIP2-City-Test.mmdb` is MaxMind's public test database, copied unchanged from
https://github.com/maxmind/MaxMind-DB/blob/main/test-data/GeoIP2-City-Test.mmdb
(source data: `source-data/GeoIP2-City-Test.json` in the same repository).

It is used instead of the real DB-IP database (about 127 MB) to exercise `GeoLocator`.
`81.2.69.142` resolves to London.
